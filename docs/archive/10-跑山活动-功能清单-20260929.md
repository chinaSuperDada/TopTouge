## 争议点汇总（需要你逐条拍板）

| # | 问题 | 我的建议 |
|---|---|---|
| ① | **运营活动位（banners）与组队主页争 tab** | banners 留在首页轮播；活动 tab 让位给组队 |
| ② | **组队 Run 与现有 solo 成绩合并还是并列？** | 合并（run_records 加 team_id，单人=1人队） |
| ③ | **现有「分数+名次」体系怎么办？** | 保留为个人履历的对外成绩；组队走「时长+不排名」，两者并存 |
| ④ | **仪表盘超大计时用什么色？** | 现有 token 无橙色；建议纯白 + 青蓝辅助，不加新色 |
| ⑤ | **难度：休闲/进阶/硬核 与现有 1~5 星什么关系？** | 映射到现有星级（1-2休闲 / 3进阶 / 4-5硬核） |
| ⑥ | **P1（风险/上报/SOS）本期做不做？** | 只预留模型，不实现 |
| ⑦ | **「附近约跑」要不要？** | P0 不做（原型自己也标了风险） |
| ⑧ | **是否允许公开路线（无邀请人）？** | P0 只允许队伍码加入（原型待拍板项） |
| ⑨ | **离线路线包（G2）可行吗？** | 小程序做离线地图包极难，建议降级为「离线缓存路线几何 + 预警文本」，不做地图瓦片 |
| ⑩ | **后台定位（G5）不可用时怎么办？** | 兜底：引导屏幕常亮 + 支架；极端情况引导车机/手表采集 |
