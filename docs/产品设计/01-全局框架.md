# 模块 01 · 全局框架

> 覆盖：产品定位、信息架构、底部导航、视觉规范、全局交互与文案约定。
> 本模块是所有其它模块的公共底座——改这里的规则会影响全部页面，改动需谨慎。

---

## 1. 产品定位

**名字**：TopTouge / 跑山路线。**一句话**：记录和分享跑山路线，跑完看分数和排名。

**目标用户**：喜欢开车跑山路的车友。核心诉求是「找一条好路 → 跑一趟 → 知道自己什么水平」。

**三条主张**：

- **成绩只出面子和位次**：结果页只有「综合评分」和「本路线第 N 名」，绝不出时间速度。跑山圈子里「几分几秒」容易引发攀比与危险驾驶，产品主动回避。
- **隐私可退**：可以只在本机记录，或参与算分但原始轨迹 72 小时自动清除。
- **难度不糊弄**：星级由算法从轨迹算出，不靠人工填。

## 3. 底部导航（自定义 tabBar）

`app.json` 里 `tabBar.custom = true`，四个位置：**跑山路线 / 跑山活动 / ➕ / 我的**。

- 中间是**凸起的加号**（`create-btn`），点击弹出制作方式（搜索地点 / 地图点选 / 录制轨迹），**不切换页面**——用户选完仍停在当前 tab。
- 左右两个 tab 用 `wx.switchTab` 切换（目标页在 `tabBar.list` 里，用 `navigateTo` 会报错）。
- 各 tab 页 `onShow` 里同步 `selected`（自定义 tabBar 不会自动同步选中态）。

> ⚠️ **颜色必须写死，不能用 CSS 变量。**
> `custom-tab-bar` 渲染在 `page` 标签之外，拿不到 `app.wxss` 里定义在 `page` 选择器下的变量。用 `var()` 会**静默失效**——表现为深色底上元素变黑，看起来像「没渲染」，极难排查。改配色时手动与 `styles/tokens.wxss` 同步。

## 4. 视觉规范（`styles/tokens.wxss`）

参考设计取色：**接近纯黑的深色底 + 亮青蓝 `#0c9cfc`（主强调）+ 草绿 `#6c9c3c`（辅）**。强调色在原参考图里只占 6.5% 像素，是点缀用法，**不要大面积铺**。

| 类别 | 变量 | 值 |
|---|---|---|
| 背景（三级递进） | `--bg-base` / `--bg-surface` / `--bg-elevated` / `--bg-inset` | `#080808` / `#141414` / `#1c1c1c` / `#000000` |
| 文字 | `--text-primary` / `--text-secondary` / `--text-tertiary` | `#f8f8f8` / `#b8b8b8` / `#6e6e6e` |
| 主强调 | `--accent` | `#0c9cfc` |
| 次强调 | `--accent-alt` | `#6c9c3c` |
| 功能色 | `--success` / `--danger` / `--warn` | `#6c9c3c` / `#e5484d` / `#d4a72c` |
| 星级 | `--star` / `--star-empty` | `#0c9cfc` / `#2a2a2a` |
| 圆角 | `--radius-sm/md/lg/pill` | 10 / 18 / 26 / 999 rpx |
| 间距 | `--space-1`…`--space-6` | 8 / 16 / 24 / 32 / 40 / 56 rpx（8 的倍数） |
| 字号 | `--fs-caption`…`--fs-hero` | 24 / 27 / 31 / 38 / 52 / 72 / 104 rpx |

**字号整体比常规移动端偏大**——深色底上小字更难读，且核心信息是数字。关键数字用纯白 `#ffffff` 与正文 `#f8f8f8` 拉开一丝差别。

## 5. 全局交互约定

| 场景 | 约定 |
|---|---|
| 加载态 | 列表页首次加载显示占位 / 骨架；支持下拉刷新 |
| 空态 | 无数据给一句说明，不留白屏 |
| 错误态 | 页面级失败展示白话 + 重试按钮，**不弹技术细节** |
| 防连点 | 提交类按钮（收藏 / 上传 / 评论 / 申请）进行中禁用并显示 loading |
| 定位失败 | **不阻塞任何功能**——浏览、地图、上传都照常可用，只是少了「离我最近」与蓝点 |
| 权限被拒 | 引导去 `wx.openSetting`（只有这里能改开关） |

## 6. 文案规范

### 6.1 用户文案（必须是人话）

| 场景 | 文案 |
|---|---|
| 网络不通 | 网络开小差了，请稍后再试 |
| 服务端出错 | 服务暂时不可用，请稍后再试 |
| 未检测到完整路线 | 未检测到完整完成路线，本次不计入排名 |
| 轨迹太短 | 还没采到足够的轨迹点，无法计入成绩。 |
| 需要定位权限 | 开启后才能在地图上看到你的位置、使用「离我最近」排序。 |
| 上传成功 | 直接跳详情页，**不弹**无信息量的成功提示 |

### 6.2 禁止出现的文案

**任何技术细节都不能出现在用户界面**：`errMsg`、HTTP 状态码、错误码、URL、堆栈、域名白名单提示等。这些进 `client_errors` 表给管理员看（见模块 09）。
