# 模块 02 · 路线库

> 覆盖：跑山路线首页（列表）、路线详情页（主页 / 排名两个 tab）、筛选排序、难度面板、相似路线。
> 对应后端：`routes.router` → `routeService`。

---

## 1. 首页（跑山路线）

路径 `pages/route-list/route-list`，tab 页。自上而下：**活动位轮播 → 筛选条 → 排序条 → 路线卡片列表**。

### 1.1 活动位轮播

- 横向轮播，数据来自 `GET /api/banners`（人工活动 + 算法位，按区域过滤，见模块 06）。
- 无海报图时用 `color` 做的兜底纯色块；角标显示 `tag`（本周最热 / 新路线 / 高难度）。
- 点击按 `link` 跳详情。

### 1.2 筛选条（三维筛选）

| 维度 | 选项 |
|---|---|
| 省市 | 省市联动；「全部省份」为默认 |
| 难度 | 全部 / 简单 / 较易 / 中等 / 较难 / 困难（映射 1~5 星） |
| 路型 | 全部 / 山路 / 赛道 / 非铺装 / 公路 |

### 1.3 排序条（四种排序）

| 排序 | 说明 |
|---|---|
| 热度最高 | 默认。按 `heat` 降序；热度由定时任务重算 |
| 长度最长 | 按距离降序 |
| 离我最近 | 需定位；**拿不到定位时退化为热度排序，不阻塞** |
| 最新收录 | 按创建时间降序 |

> 版主置顶的路线永远排在最前，与所选排序无关。

### 1.4 路线卡片

显示：名称、距离、难度星级、弯道数、爬升、区域。

## 2. 路线详情

路径 `pages/route-detail/route-detail`。顶部三个 tab：**路线主页 / 路线排名 / 评论**。

### 2.1 路线主页

- **地图**：画出 `displayTrack` 轨迹线，标注起点 / 终点 / 途经点；已定位时显示蓝点。起终点重合的闭环路线额外提示（外部导航对它无意义）。
- **难度面板**（`difficulty-panel` 组件）：弯道数、急弯占比、爬升、距离、路宽、综合星级。
- **操作区**：
  - 收藏（心形，实心 / 空心由详情返回的 `favorited` 决定）
  - 分享（复制高德导航链接到剪贴板，见模块 03 §4）
  - 开始跑山（进入模块 04 流程）
- **审核状态提示条**：只对未通过状态显示（见 §3）。
- **相似路线区块**：按重合度（`overlapRatio`）列出，`duplicate` 档位额外提示「可能是同一条路线」。

### 2.2 路线排名

- 成绩榜：名次、昵称头像、分数。
- **不显示用时**（主张「成绩只出面子和位次」，见模块 01 §1）。

### 2.3 评论

- 评论与路况两个区块，见模块 05。

### 2.4 审核状态文案

只对**未通过**的状态给提示条，`approved` 不显示标签（无信息量、占地方）：

| 状态 | 文案 |
|---|---|
| `pending` | 这条路线正在审核，通过后才会出现在公开列表 |
| `rejected` | 这条路线已被下架：{理由} / 这条路线已被下架 |
| `deleted` | 这条路线已被删除 |

## 3. 列表项与详情的字段裁剪

- **列表接口不返回轨迹**——一条轨迹几百个点，全量返回会让列表响应体膨胀到几百 KB。列表只给展示字段。
- **详情默认返回抽稀后的 `displayTrack`**（≤100 点），需要精确轨迹的调用方传 `?fullTrack=1`。

---

## 4. 依赖与约束

- 依赖：模块 01（全局框架）、模块 06（活动位数据）。
- 被依赖：模块 03（上传后跳本模块详情）、模块 04（从详情开始跑山）。
- 约束：星级 / 弯道等指标由后端算，前端只展示，不在前端重算。
