# 模块 08 · 版主与审核

> 覆盖：版主工作台、路线审核、本区路线管理、版主活动管理、**版主申请**。
> 对应后端：`moderator.router` → `moderatorService` / `moderatorApplicationRepo`。

---

## 1. 权限模型

**核心约束：版主只能管自己的辖区。** 每个操作都校验目标路线 / 活动是否在版主的省 / 市范围内——不能靠前端传的 id 就信任，否则版主 A 能审版主 B 城市的路线。

版主身份由 `moderators` 表指派（`userId + province + city`，一人在同一城市只能当一次）。

---

## 2. 版主工作台（`moderator`）

入口在「我的」（仅版主可见）。显示：

- 统计数字：待审数 / 本区已上架数。
- 入口：待审路线 → `moderator-review`、本区路线 → `moderator-routes`、本区活动 → `moderator-activities`。

---

## 3. 路线审核（`moderator-review`）

- 列出本区**待审**路线，按提交时间升序（先来先审，避免老的积压）。
- 操作：**通过** 或 **驳回**。
- **驳回必须填理由**——否则作者不知道为什么被拒。
- 公开路线**一律待审**；私有路线不审核（它不进公开列表，审核没有意义）。

> **无省市信息也走待审**：之前有版本对「拿不到区域」的路线直接放行，结果定位失败反而成了绕过审核的后门。现在一律 pending，审核人由辖区匹配决定（本地有版主 → 版主审；本地无版主 → 平台管理员审）。

---

## 4. 本区路线管理（`moderator-routes`）

- 列出本区**已上架**路线。
- 操作：
  - **置顶 / 取消置顶**：置顶的路线在列表永远排最前。
  - **下架**：把审核状态打回 `rejected`，作者仍能在「我的路线」看到并能改后重传。
  - **删除**：从公开列表彻底移除（**软删**，不物理删行——下面挂着别人的评论与成绩）。

> **下架与删除的区别**：下架只是打回已驳回，作者侧可见可改；删除是彻底移除。作者看到的结果不同，所以是两个独立操作。

---

## 5. 版主活动管理（`moderator-activities`）

- 新建活动（标题、副标题、时间、配色）。
- 发布 / 下线（`status` 在 `draft` / `published` 之间切换）。
- 只能管本区活动（`province/city` 自动取版主辖区）。

---

## 6. 版主申请（`moderator-apply` / `moderator-apply-review`）

> **本模块为在建功能**（2026-09-29 起并行开发中）。

### 6.1 申请资格

| 条件 | 要求 |
|---|---|
| 贡献路线 | ≥ 1 条 |
| 完成跑山 | ≥ 1 次 |

不满足时展示**进度条式的「差什么」**（`0 / 1 条`），而不是只说「不符合条件」——要告诉用户还差多少。

### 6.2 申请流程

```
我的 → 版主申请
   · 已是版主 → 显示「你已经是版主了」，不显示表单
   · 有待审申请 → 不能再提交（防连点攒出一堆重复申请）
   · 满足条件 → 填负责区域（省市）+ 理由（选填）→ 提交
   ↓
管理员审批（moderator-apply-review）
   · 通过 → 写入 moderators 表，用户成为版主
   · 驳回 → 带理由，用户可在申请记录里看到
```

### 6.3 条件快照

提交申请时把当时的 `routeCount / runCount` **快照下来**——之后用户删了路线也不影响已提交的申请，否则管理员审批时看到的依据会在脚下变。

### 6.4 状态展示

申请记录显示状态：`pending` 审核中 / `approved` 已通过 / `rejected` 已驳回。
