## 四、详细功能介绍

用于备案、审核说明、或需要解释功能时。

### 核心功能

**1. 路线库**
浏览车友分享的跑山路线。每条路线展示距离、弯道数、急弯占比、爬升高度、路宽和综合难度星级（1-5 星）。点击进入可在地图上看完整轨迹，标注起点、终点和途经点。

**2. 路线制作**
两种方式：
- **搜索规划**：输入起点和终点，可添加途经点（最多 5 个），系统自动规划出贴真实道路的路线
- **地图点选**：在地图上依次点击连成路线
- **录制**：跑一段路，自动记录轨迹并生成路线

上传后系统自动计算难度指标，无需手动填写。

**3. 跑山成绩**（开发中）
跑完一条路线后可记录成绩，系统按完成时间计算综合评分（0-1000）和该路线内的排名。为保护隐私，原始轨迹数据 72 小时后自动清除，仅保留评分和排名。

**4. 车友互动**
每条路线下可发表评论、发布路况提示（如落石、施工、湿滑）。

**5. 外部导航**
生成的路线可直接在高德地图中打开，按完整路线（含途经点）导航。

### 差异点

- **难度量化**：不是笼统的"难/易"，而是基于弯道密度、急弯占比、爬升梯度算出的 1-5 星
- **路线可复跑**：不是只给个地点的收藏夹，而是能导航复跑的完整轨迹
- **成绩可比**：同一条路线上的成绩可横向对比

## 五、服务类目选择

**推荐：汽车 → 汽车服务**

理由：既贴合"车友跑山"的产品定位，又明确在 `wx.getLocation` 接口支持的服务类目列表内。

备选（按适配度）：

| 类目 | 适配度 | 说明 |
|---|---|---|
| 汽车 → 汽车服务 | ★★★ | 推荐，支持定位接口 |
| 旅游 → 景点/线路 | ★★☆ | 贴合"路线"，但不提车 |
| 工具 → 效率 | ★☆☆ | 最容易过，但可能支撑不了定位权限 |
| 交通服务 → 导航 | ★★★ | 最贴切，但审核可能要求交通运输资质 |

> 导航类目要求《网络预约出租汽车经营许可证》之类的资质，个人/小微主体申请容易被拒。**先选汽车服务**。

## 六、⚠️ 主体类型（关键）

**个人主体做不了这个应用。**

原因：

```
采集跑山轨迹 → 需要 wx.getLocation
              → 该接口仅对特定服务类目开放
              → 且「仅限国内主体」
              → 个人主体不符合
```

另外导航、地图、交通出行类目个人主体**无法选择**。

| 主体类型 | 能否完成 | 说明 |
|---|---|---|
| 个人 | ❌ | 用不了定位，录不了轨迹 |
| **个体工商户** | ✅ | **推荐**，营业执照好办、成本低 |
| 企业 | ✅ | 可以，但成本更高 |

**建议：注册个体工商户**，经营范围包含「信息技术服务」或「软件服务」即可。

## 八、审核时可能被问到的问题

**Q：为什么要用定位？**
A：用于记录用户跑山时的实际轨迹，以及判断是否到达路线终点。定位数据仅用于生成本地轨迹，原始数据 72 小时后自动清除。

**Q：会不会采集用户隐私？**
A：不采集。不使用用户身份信息，定位数据仅用于轨迹记录，且不与他人共享。

**Q：为什么需要地图功能？**
A：路线以地图轨迹的形式呈现，用户需要在地图上查看路线走向、起点终点位置。

## 九、上线前还需要做的配置

小程序审核通过后，在「开发 → 开发管理 → 开发设置 → 服务器域名」里添加：

```
request 合法域名：https://restapi.amap.com
```

这是地点搜索和路线规划功能依赖的高德接口。**不配置的话，发布后搜索功能会失效**（开发版不受影响）。
